# FF3風RPG - カスタマイズ可能なWebゲーム

GitHub Pagesで動作するFF3（ファイナルファンタジーIII）風のターン制RPGです。

## 機能

### ✨ ゲーム機能
- **3人パーティシステム** - 複数のキャラクターで冒険
- **10種類の職業** - 戦士、魔法使い、僧侶、盗賊、黒魔導士、白魔導士、狩人、ナイト、忍者、モンク
- **10ステージ** - イノシシの森から魔王の玉座まで
- **ターン制バトル** - 攻撃、魔法、防御のアクション選択
- **レベルアップシステム** - ステージクリアでステータス上昇
- **ゴールド報酬** - ステージクリアで経験値獲得

### 🎨 カスタマイズ機能
- **キャラクター名変更** - 好きな名前をつけられる
- **職業選択** - 各キャラクターの職業をカスタマイズ
- **ステータス表示** - HP、攻撃力、防御力、魔力、精神力を確認

### 💾 セーブシステム
- **5つのセーブスロット** - 複数のゲーム進行を同時に管理
- **ローカルストレージ保存** - ブラウザに自動保存
- **ロード機能** - 過去のセーブデータを読み込める

## 遊び方

### 1. 新規ゲーム開始
メニューから「新規ゲーム」を選択してください。

### 2. パーティ編成
- 3人のキャラクターに名前をつける
- 各キャラクターの職業を選択
- 「決定」を押してゲーム開始

### 3. バトル
- **攻撃** - 物理攻撃で敵にダメージを与える
- **魔法** - 魔法攻撃で敵にダメージを与える（魔力が高いほど威力UP）
- **防御** - その turn の防御力をアップさせる
- **セーブ** - 現在の進行状況を保存

### 4. クリア条件
- 10ステージ全てをクリアするとゲームクリア！

## 技術仕様

- **言語** - HTML5, CSS3, Vanilla JavaScript
- **保存** - localStorage（ブラウザローカルストレージ）
- **ホスティング** - GitHub Pages
- **ブラウザ対応** - すべてのモダンブラウザ

## セーブデータの場所

セーブデータはブラウザの LocalStorage に保存されます：
- Chrome/Edge: DevTools → Application → Local Storage
- Firefox: DevTools → Storage → Local Storage

## トラブルシューティング

### セーブが読み込めない
- ブラウザのプライベートモード/シークレットモードを使用している場合、ローカルストレージが無効です
- 通常のモードで起動してください

### ゲームが起動しない
- ブラウザのコンソール（F12）でエラーメッセージを確認してください
- JavaScript が有効になっているか確認してください
